# 달 탐사 개발용 Webots 맵

LIMO 4대, 언덕 3개, 크레이터 3개 및 움직이는 태양·그림자로 구성된 **맵 전용** 배포 폴더입니다. 로봇은 정지 상태이며, 태양과 그림자만 자동으로 움직입니다. 기존 main 파일의 수정 없이 폴더 전체를 추가하여 사용할 수 있습니다.

## 실행 환경과 방법
- Webots R2025a 및 Webots Python 컨트롤러를 실행할 수 있는 Python 3.
- ROS 2, Nav2, Pygame, NumPy, SpiceyPy, 학습 모델은 필요하지 않습니다.
- Linux 권장 실행:
```bash
cd moon_map_release
bash run.sh
```
폴더를 다른 경로에 놓아도 됩니다. 실행기는 PATH의 webots, WEBOTS_HOME, /usr/local/webots 순서로 프로그램을 찾습니다. 개인 설정을 복사하지 않고 `.runtime/`에 최소 설정을 생성하여 그림자를 활성화합니다.

Windows/macOS에서는 Webots에서 `worlds/moon_terrain.wbt`를 직접 열고 재생하세요. Preferences의 Shadows 설정이 켜져 있어야 합니다. Linux에서도 맵을 직접 열 수 있습니다.

## 맵 구성
- 20×20m 지면, 중력 9.81m/s² (주행 비교용 지구 중력).
- LIMO 4대: 왼쪽 구석에 2×2, 1.4m 간격. 로봇 크기는 축소하지 않았습니다.
- 언덕 3개: 높이 0.8m, 지름 2~2.56m.
- 크레이터 3개: 지름 1.44~1.76m. 테두리를 높인 분지 모형이며 지면을 뚫은 구멍이 아닙니다.
- 가장자리 경계벽: 높이 0.5m. 주 화면에서만 숨기고, 라이다·로봇 카메라와 물리 충돌에는 유지합니다. 경계벽 자체는 그림자를 만들지 않습니다.
- 로봇 모델의 RGB·깊이 카메라에는 근거리 관측을 위한 하향 기울기와 160×128 해상도가 설정되어 있습니다. 정지 컨트롤러에서는 센서를 활성화하거나 영상을 발행하지 않습니다.

## 태양과 그림자
맵에 지정된 `lunar_sun` Supervisor가 자동 실행됩니다.
- 태양 고도: 15도 고정. 밤으로 전환되지 않습니다.
- 방위각: 서쪽 270도에서 시작하여 시뮬레이션 240초마다 한 바퀴 회전합니다.
- 좌표: +X 동쪽, +Y 북쪽, +Z 위쪽.
- 표시는 가상의 통제된 조명입니다. 실제 달의 날짜·위도에 따른 천체 궤적은 사용하지 않습니다.
- 밝은 구체는 태양 방향 표시용이며 실제 태양 크기·거리 모형이 아닙니다.
- 일시정지하면 태양도 멈추고 재생하면 다시 움직입니다. 120초 자동 정지나 종료 제한은 없습니다.

`controllers/lunar_sun/sun_config.json`에서 고도, 초기 방위각, 회전 주기를 바꾼 후 맵을 다시 로드하면 됩니다. 고도는 0~90도 사이, 주기는 양수여야 합니다. `mode`는 `constant_elevation`을 유지하세요.

## 포함 범위
이 폴더에는 맵, 로봇 모델·메시, 달 텍스처, 태양 컨트롤러, 정지 컨트롤러와 실행 문서만 들어 있습니다. 임시 탐사, 경로 계획, SLAM, 미래 그림자 예측, ROS 토픽, 시험 평가기, SPICE 데이터, 가상환경, 학습 데이터는 포함하지 않습니다.

파일을 하나씩 옮기지 말고 이 폴더 구조 전체를 유지하세요. 지도 없는 탐사를 개발할 때는 월드의 지형 좌표를 로봇에게 미리 제공하지 않고 센서 관측으로 정보를 구성해야 합니다.

## 배포 전 확인
Python 문법, 로컬 파일 참조, 네 로봇의 정지 컨트롤러 연결, 태양 방향의 단위 길이·고정 고도·회전 주기, 시험 코드 의존성 제거를 확인했습니다. 다른 노트북에서의 실행은 아직 검증하지 않았습니다.

출처 및 라이선스 관련 고지는 `THIRD_PARTY_NOTICES.md`를 참고하세요.
